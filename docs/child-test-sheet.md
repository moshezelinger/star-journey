# דף תצפית: ילד משחק בגני הרוח (כוכב 1)

הדף הזה מיועד למבוגר שיושב ליד הילד בזמן המשחק הראשון. המטרה היא להבין איפה המשחק ברור ואיפה הוא לא, ולא לבחון את הילד. לא עוזרים אלא אם הילד מבקש, או אם הוא תקוע יותר משתי דקות באותו מקום.

## לפני שמתחילים

- גרסה (commit): ____________ &nbsp; מכשיר ודפדפן: ____________ &nbsp; מסך: מחשב / טלפון לרוחב / טאבלט
- גיל הילד: ____ &nbsp; שיחק בעבר במשחקי פלטפורמה תלת־ממדיים? כן / לא
- פותחים את המשחק עם `?tune` בכתובת ומסתירים את הלוח (מקש ` או כפתור ⚙). כך זמני הקטעים נרשמים בלוח, ואפשר לפתוח אותו בסוף ולהעתיק אותם.
- אומרים לילד רק דבר אחד: "אחיו של הגיבור אבוד. נסה למצוא אותו." לא מסבירים מקשים מעבר להודעה שעל המסך.

## מה לבדוק (לסמן ולכתוב מה ראיתם)

**הפנס**

**אגרוף וקפיצה כפולה**
- [ ] שבר את הארגז בלי עזרה. ניסיונות: ____

- [ ] הבין שאפשר לקפוץ שוב באוויר רק מתוך ההודעה, בלי הסבר נוסף.

**אויבים**
- [ ] ראה את סימן הקריאה של הגומבה וזז הצידה, או נפגע. ____________
- [ ] שם לב לצל של הקופה (וגם לטבעת שלו בלילה) לפני הצלילה.

**הרוח והגשר**
- [ ] הסתכל על הדגלים לפני הקפיצה, או אמר משהו על הרוח.
- [ ] כיוון את הקפיצה מעל הרווח. ניסיונות עד שעבר: ____ &nbsp; נפילות לתהום: ____
- [ ] נפל ולא נבהל מהחזרה לדגל (שימו לב לתגובה).

**הטחנה והבלם**
- [ ] מצא את הידית האדומה והבין שצריך להכות בה.
- [ ] הבין שרק הכנף עם הסולם (והדגלון האדום) טובה. ניסיונות: ____
- [ ] אחרי כנף שגויה, הבין שהבלם משתחרר ואפשר לנסות שוב.
- [ ] האם חלון העצירה (±22°) קל מדי, מתאים או קשה מדי? ____________

**מצלמה ותצוגה**
- [ ] המצלמה לא הסתירה את הגיבור בתעלה, על הגשר או במרפסת.
- [ ] בלילה עדיין ראה את השביל, את שפת הקרשים ואת הרווח.
- [ ] במגע: הזיז ופנה במבט באותו זמן, ותפס זום בלי להפעיל אגרוף בטעות.
