# Star Journey: notes for agents

- Browser game, Three.js r128, no build step. Star 1 (Wind Gardens) lives in `js/wind-gardens.js`, star 2 (Basalt Mines) in `js/basalt-mines.js` (`docs/basalt-mines.md`), star 3 (Ink Swamp) in `js/ink-swamp.js` (`docs/ink-swamp.md`), star 4 (Furnace Moon, the last one) in `js/furnace-moon.js` (`docs/furnace-moon.md`); `index.html` reaches each through the `LEVELS` table; character models in `js/models.js`; shared state in `js/shared.js`; tuning, `FX` switches and `QUALITY` tiers in `js/tuning.js`; day and night in `js/day-cycle.js`; the Suno songs in `js/music.js` (one player, one table of tracks, `assets/music/license.txt`).
- **Performance rules: `docs/performance-rules.md` (draft, awaiting Moshe's approval).** Follow its budgets and techniques for every visual change: instancing for repeats, the shared kit (`box()`, `cyl()`), `mergeStatic` for static parts, shader animation for many objects, one shadow-casting light, an `FX` switch for each costly effect.
- Before each commit run `node tools/route-check.js`, `mines-check.js`, `swamp-check.js`, `furnace-check.js`, `day-check.js`, `touch-check.js`, `camera-check.js`, `music-check.js` (run `npm install` in `tools/` once). For visual changes also `node tools/frames.js`, and record draw calls and triangles before and after.
- Work on a branch, never merge to `main` without Moshe playing it. Report progress on the GitHub issues using the follow-up record format in issue #1, in Hebrew.
- **Characters are built in code** in `js/characters.js` (Moshe, 21.11.2026: improve them with what the game already has, no GLB per character). Each one is an original design in the role the story needs (the brother, the mushroom walker, the winged turtle and so on), not a copy of an existing character. Read `docs/characters.md` before changing one: a character is a few rigid parts, each merged into one mesh with vertex colours, and keeps the parts and sizes the level code moves. For a character change also run `node tools/lineup.js` and `node tools/char-frames.js <label>`, and record draw calls and triangles before and after.
- The models already installed stay as they are (the hero, Bowser, and on stars 2 to 4 the big ape, the dinosaur, the mushroom friend and on star 3 the swamp plant), loaded through `js/models.js`; their code versions show with `?models=code`. Keep the licence file and the credit in `README.md` for each of them, and the fan-project notice.
